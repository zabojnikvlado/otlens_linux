# Web UI investigation and layout polish

Implemented:

- incident timeline wrapping that prevents long alert types and messages from overlapping;
- Central Data Management operation for deleting incident history;
- horizontal, non-stacking VLAN chips in the topology toolbar without changing topology physics;
- compact Device category filter chips;
- structured Device category selector with extended IT/OT device classes;
- clickable DNS rows with query/response, record/rcode names, CNAMEs, answers, TTL expiry and alert correlation;
- clickable Alert rows with first/last seen, alert key, review data, count and structured evidence when supplied;
- compact Asset table row and action-button sizing consistent with the other data tables.

The topology physics, gravity, stabilization and node animation settings were not changed.
