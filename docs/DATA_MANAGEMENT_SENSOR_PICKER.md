# Data Management sensor picker

The **Reset selected sensors** action no longer depends on navigating to the Sensors tab.

Flow:

1. Choose the sensor reset operation in Data Management.
2. Click **Reset selected sensors**.
3. Select one or more sensors in the modal. The list supports search and selecting all visible sensors.
4. Type `RESET` and submit.

Selections made on the Sensors tab are used as optional defaults, but are not required. Sensor data is fetched for users who can view either the Sensors tab or Data Management.
