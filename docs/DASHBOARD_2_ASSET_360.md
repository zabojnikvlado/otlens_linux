# Dashboard 2.0 and Asset 360°

This release turns the overview into an operational command centre and extends the asset modal into a unified investigation workspace.

## Dashboard 2.0

- immediate-attention score combining critical alerts, offline sensors, and vulnerability exposure
- identity coverage, stale inventory, and exposure indicators
- prioritised action queue with direct navigation
- asset risk posture visualisation based on alerts, incomplete identity, lifecycle state, and healthy inventory

## Asset 360°

- overview with risk, identity, exposure, lifecycle, and recommended next actions
- security panel combining detections, vendor-matched advisories, and observed services
- unified timeline combining first/last seen, reconnaissance profile updates, and security alerts
- retained identity, lifecycle, services, evidence, IP history, and recon history panels
