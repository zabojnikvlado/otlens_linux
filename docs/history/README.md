# Development history

This folder holds the phase-by-phase development log OTLens was built
from — one file per feature/fix as it was implemented, in the order it
happened. It's kept as historical record (why something ended up the way
it did), not as user-facing documentation.

**For actual documentation, see [`../../DOCUMENTATION.md`](../../DOCUMENTATION.md).**

These files are not maintained going forward and may reference file paths,
ports, or behavior that's since changed — if something here conflicts with
`DOCUMENTATION.md`, trust `DOCUMENTATION.md`.
